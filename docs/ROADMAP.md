# Delivery Roadmap — BitesBro

| Phase | Scope | Exit criteria |
|---|---|---|
| 0 — Confirm | Requirements, roles, privacy, policy and finance decisions | Client approvals recorded |
| 1 — Foundation | PWA shell, Auth, schema, RLS, environments and CI | Migrations and access tests pass |
| 2 — Core MVP | Menu with availability and categories; customer Menu/Cart/Orders experience and checkout; server-side price/tax validation; pending order before payment; verified status transitions; kitchen queue; preparing/ready updates; administrator menu editing; daily totals and invoice breakdown; payment exception queue with named checker, evidence and audit trail. | End-to-end pilot test passes |
| 3 — Harden | Audit, concurrency, error recovery, retention, restore and operations | Acceptance tests and restore drill pass |
| 4 — Expand | AI food-demand forecasting, loyalty program, complex driver location tracking, advanced dispatch, native apps and automatic gateway migration are later possibilities, not first-release commitments. | Separate scope, budget and approval |

Do not skip Phase 0 or introduce real personal/order/payment data before security, privacy
and operational approvals are complete.
